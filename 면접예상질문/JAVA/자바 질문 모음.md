### Q : 프로그래밍이란 무엇인가?

```text

컴퓨터에게  코드를 통해 명령을 시킨다.
```
---

### 꼬리질문
#### Q : 컴퓨터에게 명령을 시키는 이유는?
```text
비용 측면에서도, AWS 같은 클라우드 기준으로 한 대의 서버(예: t3.medium)를 하루 24시간 돌려도 하루 2~3천 원 수준입니다.
사람이 같은 양의 일을 한다면 인건비로 하루 수십만 원 이상이 들겠죠.
인간은 24시간 기준, 80배 비쌉니다.

실제로 CPU는 초당 수십억 번(약 3GHz = 30억 회)의 연산을 수행할 수 있고
Intel Pentium 4(3 GHz) — 2002년 기준으로 3GHz

수천~수만 배 이상차이가 납니다.
```
---
#### Q : 프로그래밍 언어란?
```text
컴퓨터는 1,0(binary) 모른다. 
프로그래밍 언어로 작성된 내용을 컴파일러라는 녀석이 바이너리화 해서 컴퓨터가 실행할 수 있는 상태를 만들어야만 컴퓨터가 동작된다.

java는 jit-compiler→ interpreter + 정적 컴파일러 혼합된 하이브리드 언어입니다
```
---
#### Q : 객체지향 프로그래밍이란 무엇인가요?

```text
객체 단위로 프로그래밍을 개발하되 중복된 코드 제거와 가독성을 생각하며 개발하는 프로그래밍 패러다임(10년 주기로 유행, 패턴)입니다.
여기서 객체란  현실세계의 사물을 객체화하는데, class 키워드로 proerty, method 정의한 후  new 키워드로 heap 메모리에 올라가있는 상태입니다.
```
---

```text
객체를 만들기 전 설계도(변수(property) , 함수method)입니다.
```

#### 배열에 대해서 설명해주세요
```text
고정된 물리 공간에 연속된 변수 타입이 할당된 자료구조입니다.
특징은 크기가 고정되어 있고, 메모리연속적으로  저장됩니다.
장점은  인덱스로 접근가능하여 O(1) 조회가능합니다. 단점은  길이가 정해져 있어서 크기 변경이 어렵습니다.
중간에 데이터를 추가하거나 삭제할때  한칸씩 옮겨야 해서 비용이 큽니다.
크기가 고정된 데이터를 다룰때 좋습니다.
```

#### 리스트가 뭔가요?
```text
리스트는 논리적 물리공간에 데이터가 저장됩니다. 노드간 데이터 (헤더/바디)
헤더에 다음 노드 주소가 저장된다. 
장점: 고정되어있지 않기에 추가노드 생성이 자유롭다.
단점: 메모리 2배쓴다? 조회가 느리다. 노드간 전체순회 O(n) 조회
예시: 상품을 등록한다
```

#### overloading 이란?
```text
같은 이름의 메서드에 파라미터 개수가 여러개로 생성하여 기능을 분리하기 위한 것입니다.
오바로딩을 통해  코드재사용이 높아지. 가독성 좋아집니다.
```

---

#### overrding이란?
```text
class간 계층구조에 부모메서드로 구현된 메서드르 자식 class 재구현하여 메서드명은 같지만 
class 동작시 다형성을 이루게하는 조건중에 하나입니다.
```
